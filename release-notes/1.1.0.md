## New

- **`macup` in the terminal.** The app now answers as `macup`, with the menu bar app's own settings, ignored packages and history: `macup` shows what is ready, `macup check` checks now, `macup upgrade` does what Update All does (`--now`, `--dry-run`, `--skip-admin`), and `macup ignore` / `unignore` share the app's list. The Homebrew cask links it for you; a downloaded copy can install the link from Settings. The app and the terminal never update at the same time.
- **macOS updates are hidden unless you ask for them.** System Settings already announces them, and MacUp can only hand them off there. Turn on "Show macOS updates" in Settings to list them again.

## Fixed

- **Homebrew casks that need your password, such as Docker Desktop, no longer fail halfway.** Their upgrade runs part of itself through sudo, which can only ask for a password in a terminal. MacUp now spots them, leaves them out of Update All and scheduled updates, and offers **Update in Terminal**, where sudo asks for the password itself. MacUp never sees it.
- **"Homebrew: could not check for updates" and "macOS: could not check for updates" after 180 seconds.** Homebrew's daily self-update can stall fetching taps; it is now cut short and the check answers from what is already on disk. macOS's update service can be busy for minutes; MacUp now reads the list macOS keeps for itself instead of waiting.
- A check that times out now stops everything the manager started, and a tool that hangs even when asked its version can no longer hold up the whole scan.
- pnpm 9 to 12 all check, update and remove correctly, including on a Mac with no global packages yet (#17).
- Update All no longer opens a "You're up to date" window for MacUp itself; a window appears only when there is an update.
- A package manager you turned off no longer keeps its last error on screen.
- The menu bar icon keeps its shape on menu bars shorter than the icon (#19).
